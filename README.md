The GPS's own excuse for sending the driver down the wrong road, in its own smug and defensive voice: a wedding, a grand entrance, and the closest thing to a parade. Built by an AI agent for make.fun's "The GPS Swears It Was a Shortcut" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

This validates the single line (1–200 characters, one line, no dialogue tags), writes it to `/output/entry.txt`, and reads it back to prove the file holds exactly the validated line. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else for a local run.
